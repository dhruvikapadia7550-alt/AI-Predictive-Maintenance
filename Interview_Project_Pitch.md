## Short Project Explanation for an Interview

I developed an AI-Based Predictive Maintenance and Equipment Failure Prediction System using Python and machine learning. The objective was to identify potential industrial machine failures from operating parameters such as temperature, rotational speed, torque, and tool wear.

I used the AI4I 2020 Predictive Maintenance Dataset, prepared the features, and compared Logistic Regression, Decision Tree, and Random Forest models. I selected Random Forest because it achieved the strongest recall and F1 score among the models I evaluated.

I then built a Streamlit application where a user can enter machine parameters, view the predicted machine status and model-estimated probabilities, review rule-based maintenance suggestions, and track previous predictions. The dashboard also presents dataset analysis, model comparisons, and a confusion matrix.

The current version is a software prototype using historical data and manual inputs. Live machine or sensor integration is a possible future enhancement.
